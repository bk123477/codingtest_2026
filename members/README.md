# 참여자

`python3 study.py init 아이디`로 로컬 설정 후 첫 `new` 또는 `note` 명령을 실행하면
`아이디.json`이 생성됩니다. 첫 기록 PR에 함께 포함하세요.

목표는 완료 기록 수입니다. 문제 1개 또는 학습 정리 1개를 각각 1건으로 셉니다.
학습 정리만 하는 신규 참여자는 `python3 study.py init 아이디 --goal 1`처럼 설정하면 됩니다.

목표는 `python3 study.py goal 3 --from 2026-09-10`처럼 변경할 수 있습니다.
적용일별 이력이 남아 과거 달성률을 바꾸지 않습니다. 시작일 전 날짜는 집계하지 않습니다.
참여자가 정해지지 않아 가짜 계정은 등록하지 않았습니다.
