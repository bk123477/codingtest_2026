# 공부 기록

`YYYY/MM/DD/GitHub아이디/기록명/`에 기록이 쌓입니다.

날짜 → 참여자 폴더를 열면 자동 생성된 일일 기록 목록을 볼 수 있습니다.
각 문제는 `README.md`(설명), `solution.*`(코드), `meta.json`(자동 집계 정보)으로 구성합니다.
학습 정리는 `note-01/`처럼 저장하며 `README.md`와 `meta.json`만 있으면 됩니다.
`note --source`로 기존 글을 가져왔으면 `notes.md`도 함께 생성됩니다.
같은 날 문제와 학습 정리를 모두 작성해도 하나의 일일 목록과 PR에 들어갑니다.

전체 현황은 루트 README의 **학습 현황** 링크에서 확인하세요.
