## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
재료가 주어진 순서대로 쌓일 때, 아래부터 `빵-야채-고기-빵`인 연속 재료를 즉시 포장해 제거한다. 모든 재료를 처리한 뒤 포장한 햄버거의 개수를 구한다. 재료 배열의 길이는 최대 1,000,000이다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
재료를 `deque`에 쌓고, 네 개가 모일 때마다 뒤에서 네 개를 꺼내 확인한다. 꺼낸 순서가 위에서부터 `1, 3, 2, 1`이면 햄버거를 하나 세고, 아니면 네 재료를 원래 순서로 다시 넣어 다음 재료를 처리한다. 이는 가능한 조합을 모두 시도하는 완전 탐색이 아니라, 쌓이는 과정을 그대로 흉내 내는 스택 시뮬레이션이다.

## 확인한 예제 / 경계 조건

문제 제공 예제 `ingredient=[2, 1, 1, 2, 3, 1, 2, 3, 1]`의 예상 결과는 `2`이다. 정확히 한 개의 조합만 있는 `ingredient=[1, 2, 3, 1]`에서는 `1`, 유효한 순서가 없는 `ingredient=[1, 3, 2, 1]`에서는 `0`이 된다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 공간: `O(n)`

'''
def solution(ingredient):
    s = []
    cnt = 0
    for i in ingredient:
        s.append(i)
        if s[-4:] == [1, 2, 3, 1]:
            cnt += 1
            for i in range(4):
                s.pop()
    return cnt
'''
