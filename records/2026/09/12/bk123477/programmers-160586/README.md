## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
각 키에서 문자를 입력하는 데 필요한 최소 누름 횟수를 구해 여러 문자열을 작성한다. 어떤 키에도 목표 문자가 없으면 해당 문자열의 결과는 `-1`이다. `keymap`과 `targets`의 원소 길이는 각각 최대 100이다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
각 목표 문자를 모든 키 문자열에서 찾고, 해당 키에서 처음 등장하는 위치(`index + 1`) 중 최솟값을 누름 횟수로 선택한다. 한 문자라도 입력할 수 없으면 현재 목표 문자열의 합계를 `-1`로 바꾸고 다음 목표로 넘어간다.

## 확인한 예제 / 경계 조건

문제 제공 예제 `keymap=["ABACD", "BCEFD"]`, `targets=["ABCD", "AABB"]`의 예상 결과는 `[9, 4]`이다. `keymap=["AA"]`, `targets=["B"]`처럼 어떤 키에도 문자가 없으면 `[-1]`이 된다. 같은 문자가 여러 키에 있으면 각 키의 첫 위치 중 최솟값을 사용한다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: `O(TKL)` (`T`는 모든 target 문자 수, `K`는 키 개수, `L`은 가장 긴 키 문자열 길이)
- 공간: `O(T)` (결과 배열 포함, 결과를 제외한 추가 공간은 `O(1)`)
