## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
두 문자열에서 서로 짝지을 수 있는 공통 숫자만 사용해 만들 수 있는 가장 큰 수를 문자열로 반환한다. 공통 숫자가 없으면 `-1`, 결과가 0으로만 구성되면 `0`을 반환한다. 각 문자열의 길이는 최대 3,000,000이다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
두 문자열의 숫자별 등장 횟수를 `defaultdict`에 세고, 각 숫자에 대해 두 횟수의 최솟값만 공통 개수로 사용한다. 9부터 0까지 공통 숫자를 반복해 내림차순 문자열을 만들고, 결과의 첫 문자가 0이면 `0`, 결과가 비어 있으면 `-1`을 반환한다.

## 확인한 예제 / 경계 조건

문제 제공 예제 `X="5525"`, `Y="1255"`의 예상 결과는 `"552"`이다. 공통 숫자가 없는 `X="100"`, `Y="2345"`에서는 `"-1"`, 공통 숫자가 0뿐인 `X="100"`, `Y="203045"`에서는 `"0"`이 된다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: `O(|X| + |Y|)`
- 공간: `O(1)` (숫자 10개의 카운터와 결과 문자열을 제외한 기준)
