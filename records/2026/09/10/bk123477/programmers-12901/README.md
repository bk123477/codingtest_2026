## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
2016년의 특정 월 `a`와 일 `b`가 주어질 때, 해당 날짜의 요일을 `SUN`부터 `SAT` 중 하나로 반환한다. 2016년은 윤년이므로 2월을 29일로 계산한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`months`에 월별 일수를 저장하고, 1월 1일부터 주어진 날짜까지 지난 일수를 계산한다. `(days - 1) % 7`을 이용해 1월 1일의 요일인 금요일부터 시작하는 `week` 배열의 인덱스를 구한다.

## 확인한 예제 / 경계 조건

- `a = 5`, `b = 24` -> `"TUE"`
- `a = 1`, `b = 1` -> `"FRI"` (기준 날짜)
- 윤년인 2016년의 2월은 29일로 계산해야 하며, 월별 누적 일수에 현재 날짜를 더한 뒤 하루를 빼고 요일을 계산한다.

## 복잡도 (선택)

- 시간: O(a) (`a`는 월)
- 공간: O(1)
