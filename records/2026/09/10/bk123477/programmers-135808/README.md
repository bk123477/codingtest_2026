## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
사과를 한 상자에 `m`개씩 담을 때, 상자 안의 최저 점수 사과 점수에 `m`을 곱한 가격의 합이 최대가 되도록 구성한 이익을 반환한다. 상자에 담지 못한 사과는 버린다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
점수를 오름차순으로 정렬한 뒤 큰 점수부터 `m`개씩 꺼낸다. 한 묶음에서 마지막으로 꺼낸 값이 그 상자의 최저 점수이므로, 묶음이 `m`개일 때만 그 값과 `m`을 곱해 이익에 더한다.

## 확인한 예제 / 경계 조건

- `k = 3`, `m = 4`, `score = [1, 2, 3, 1, 2, 3, 1]` -> `8`
- `k = 4`, `m = 3`, `score = [4, 1, 2, 2, 4, 4, 4, 4, 1, 2, 4, 2]` -> `33`
- 전체 사과 수가 `m`의 배수가 아니면 정렬 후 남는 일부 사과는 판매하지 않으며, 완성된 상자만 이익에 반영한다.

## 복잡도 (선택)

- 시간: O(S log S) (`S`는 `score` 길이)
- 공간: O(S)
