## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
`aya`, `ye`, `woo`, `ma`를 이어 붙여 만들 수 있지만 같은 발음을 연속해서 사용할 수 없는 단어의 개수를 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
각 단어를 앞에서부터 읽으며 첫 글자에 맞는 발음의 나머지 글자를 직접 확인하고, 직전에 사용한 발음과 같으면 실패 처리한다. 끝까지 정확히 소비한 단어만 발음 가능한 단어로 센다.

## 확인한 예제 / 경계 조건

- `babbling = ["aya", "yee", "u", "maa"]` -> `1`
- `babbling = ["ayaye", "uuu", "yeye", "yemawoo", "ayaayaa"]` -> `2`
- `"ayaaya"`, `"yeye"`처럼 같은 발음이 연속되면 다른 발음으로 분리할 수 있어도 허용하지 않는다.
- 발음 하나가 중간에서 잘리거나 허용되지 않은 글자가 남으면 발음할 수 없는 단어로 처리한다.

## 복잡도 (선택)

- 시간: O(B) (`B`는 모든 단어의 길이 합)
- 공간: O(1)
