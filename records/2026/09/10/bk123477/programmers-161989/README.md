## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
오름차순으로 주어진, 다시 칠해야 하는 벽의 구역들을 길이 `m`인 롤러로 모두 덮는 최소 칠하기 횟수를 구한다. 롤러는 벽 밖으로 나가면 안 되며, 필요한 구역이 아닌 곳을 함께 칠해도 된다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
구역을 앞에서부터 확인하며 마지막으로 칠한 구간 `[l_index, r_index]` 안에 있으면 건너뛴다. 범위를 벗어난 첫 구역 `i`를 포함해 오른쪽으로 최대한 덮는 롤러를 선택하고, 코드에서는 그 영향 범위를 `[i, i + m - 1]`로 관리한다. 끝점이 벽을 넘어가는 경우에도 롤러를 왼쪽으로 옮겨 벽 끝에 맞출 수 있으므로 필요한 칠하기 횟수는 같다.

## 확인한 예제 / 경계 조건

- `n = 8`, `m = 4`, `section = [2, 3, 6]` -> `2`
- `n = 5`, `m = 4`, `section = [1, 3]` -> `1`
- `m = 1`, `section = [1, 2, 3, 4]`처럼 롤러 길이가 1이면 필요한 구역마다 한 번씩 칠해야 한다.

## 복잡도 (선택)

- 시간: O(S) (`S`는 `section` 길이)
- 공간: O(1)
