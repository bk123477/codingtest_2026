## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
`x`부터 `x`만큼 증가하는 수 `n`개를 리스트로 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`0`부터 `n - 1`까지 순회하며 `x + x*i`를 리스트에 추가한다.

## 확인한 예제 / 경계 조건

`x=-4`, `n=2`이면 `[-4, -8]`을 반환한다.

## 복잡도 (선택)

- 시간: O(n)
- 공간: O(n)
