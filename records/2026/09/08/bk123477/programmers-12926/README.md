## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 `s`의 각 알파벳을 `n`만큼 민 암호문을 만든다. 공백은 밀어도 공백이며, 대소문자는 유지되고 범위를 넘어가면 순환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
문자열을 순회하며 공백은 유지하고, 대문자와 소문자의 아스키 범위를 확인하여 `n`을 더한 값이 알파벳 범위를 초과할 경우 오프셋을 조정해 순환시킨 후 문자로 변환한다.

## 확인한 예제 / 경계 조건

- `s = "AB", n = 1` -> `"BC"`
- `s = "z", n = 1` -> `"a"`
- `s = "a B z", n = 4` -> `"e F d"`

## 복잡도 (선택)

- 시간: O(n) (`n`은 문자열 길이)
- 공간: O(n)
