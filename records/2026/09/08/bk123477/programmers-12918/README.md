## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 `s`의 길이가 4 혹은 6이고, 숫자로만 구성되어 있는지 확인한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
길이가 4 또는 6이 아니면 `False`를 반환하고, 문자열을 순회하며 각 문자가 `"0"`과 `"9"` 사이인지 검사하여 숫자가 아니면 `False`를 반환한다.

## 확인한 예제 / 경계 조건

- `s = "a234"` -> 문자가 포함되어 `False`
- `s = "1234"` -> 길이 4이고 모두 숫자이므로 `True`

## 복잡도 (선택)

- 시간: O(n) (`n`은 문자열 길이)
- 공간: O(1)
