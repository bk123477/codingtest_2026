## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 `s`에 나타나는 문자를 큰 것부터 작은 순으로 정렬해 새로운 문자열을 반환한다. (대문자는 소문자보다 작은 것으로 간주)

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
문자열을 순회하며 각 문자를 리스트에 담은 뒤 `sort(reverse=True)`로 내림차순 정렬하고 `join`으로 합쳐 반환한다.

## 확인한 예제 / 경계 조건

- `s = "Zbcdefg"` -> 대문자가 뒤로 가고 소문자가 내림차순 정렬되어 `"gfedcbZ"` 반환

## 복잡도 (선택)

- 시간: O(n log n) (`n`은 문자열 길이)
- 공간: O(n)
