## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 `s`의 각 위치마다 자신보다 앞에 나오면서 가장 가까운 곳에 있는 같은 글자의 위치 차이를 구한다. 앞에 없으면 -1을 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
문자열을 순회하며 각 문자의 가장 최근 인덱스를 딕셔너리에 기록한다. 이미 등장했던 문자면 현재 위치와의 거리(`i - dic[si]`)를, 처음이면 `-1`을 저장한다.

## 확인한 예제 / 경계 조건

- `s = "banana"` -> `[-1, -1, -1, 2, 2, 2]`
- `s = "foobar"` -> `[-1, -1, 1, -1, -1, -1]`

## 복잡도 (선택)

- 시간: O(n) (`n`은 문자열 길이)
- 공간: O(k) (`k`는 서로 다른 문자 수)
