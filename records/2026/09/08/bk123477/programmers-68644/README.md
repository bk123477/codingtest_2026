## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
정수 배열 `numbers`에서 서로 다른 인덱스에 있는 두 개의 수를 뽑아 더해서 만들 수 있는 모든 수를 오름차순으로 담아 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`itertools.combinations`로 두 수의 모든 조합을 뽑아 더한 뒤, `set`으로 중복을 제거하고 `sorted()`를 통해 오름차순 정렬하여 반환한다.

## 확인한 예제 / 경계 조건

- `numbers = [2,1,3,4,1]` -> `[2,3,4,5,6,7]`
- `numbers = [5,0,2,7]` -> `[2,5,7,9,12]`

## 복잡도 (선택)

- 시간: O(n^2 log(n^2)) (`n`은 배열 길이)
- 공간: O(n^2)
