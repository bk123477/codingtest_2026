## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
표준 입력으로 주어진 가로 길이 `n`과 세로 길이 `m` 크기의 직사각형 별(`*`)을 출력한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`input()`으로 가로(`a`)와 세로(`b`)를 입력받은 뒤, 이중 반복문으로 세로 `b`줄 동안 가로 `a`개의 별을 출력한다.

## 확인한 예제 / 경계 조건

- `a = 5, b = 3` -> 가로 5개, 세로 3줄 직사각형 별 출력

## 복잡도 (선택)

- 시간: O(a · b)
- 공간: O(1)
