## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 리스트 `strings`와 정수 `n`이 주어질 때, 각 문자열의 인덱스 `n`번째 글자를 기준으로 오름차순 정렬한다. 인덱스 `n`의 문자가 같으면 사전순으로 앞선 문자열이 앞쪽에 오도록 정렬한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
인덱스 `n` 문자가 같을 때 사전순 배치를 만족하기 위해 먼저 전체 리스트를 사전순 정렬한 뒤, `lambda x: x[n]`을 키로 2차 정렬한다.

## 확인한 예제 / 경계 조건

- `strings = ["sun", "bed", "car"], n = 1` -> `["car", "bed", "sun"]`
- `strings = ["abce", "abcd", "cdx"], n = 2` -> `"abcd"`와 `"abce"`의 인덱스 2 문자가 같아 사전순 정렬되어 `["abcd", "abce", "cdx"]` 반환

## 복잡도 (선택)

- 시간: O(k · m log m) (`m`은 리스트 길이, `k`는 문자열 길이)
- 공간: O(1)
