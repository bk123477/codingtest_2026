## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
두 선수가 칼로리가 낮은 음식부터 중앙의 물(0)을 향해 먹을 수 있도록 음식을 대칭으로 배치한 문자열을 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
1번 음식부터 각 음식 개수를 2로 나눈 몫만큼 음식 번호 문자를 반복해 절반 배치를 만들고, 중앙에 `"0"`과 뒤집은 절반 문자열(`answer[::-1]`)을 이어 붙여 반환한다.

## 확인한 예제 / 경계 조건

- `food = [1, 3, 4, 6]` -> `"1223330333221"`
- `food = [1, 7, 1, 2]` -> 1개뿐인 2번 음식은 사용하지 않고 `"111303111"` 반환

## 복잡도 (선택)

- 시간: O(N) (`N`은 총 음식 개수 합)
- 공간: O(N)
