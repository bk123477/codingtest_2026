## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
놀이기구를 `count`번 탔을 때 필요한 총 금액에서 현재 가지고 있는 금액 `money` 대비 모자라는 금액을 구한다. 금액이 부족하지 않으면 0을 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
크기가 `count + 1`인 리스트에 1부터 `count`까지의 합을 누적 계산한 뒤 `price`를 곱해 총 이용료를 구하고, 현재 금액에서 차감한 값이 음수이면 모자란 금액(`abs(answer)`), 양수이면 0을 반환한다.

## 확인한 예제 / 경계 조건

- `price = 3, money = 20, count = 4` -> 총 금액 `3*(1+2+3+4)=30`, 부족한 금액 `10`
- 금액이 부족하지 않은 경우 -> `0` 반환

## 복잡도 (선택)

- 시간: O(count)
- 공간: O(count)
