## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
정수 배열 `number`에서 서로 다른 3명의 학생 번호를 더했을 때 합이 0이 되는 경우의 수를 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
3중 반복문으로 서로 다른 인덱스 3개의 조합을 모두 확인하며, 세 원소의 합이 0인 경우 카운트를 증가시킨다.

## 확인한 예제 / 경계 조건

- `number = [-2, 3, 0, 2, -5]` -> 2
- `number = [-3, -2, -1, 0, 1, 2, 3]` -> 5
- `number = [-1, 1, -1, 1]` -> 0

## 복잡도 (선택)

- 시간: O(n^3) (`n`은 배열 길이)
- 공간: O(1)
