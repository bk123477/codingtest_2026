## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
길이가 `n`이고 "수박수박수..."와 같은 패턴을 유지하는 문자열을 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`"수박"` 패턴을 `n // 2`만큼 반복하고, `n`이 홀수이면 뒤에 `"수"`를 덧붙여 반환한다.

## 확인한 예제 / 경계 조건

- `n = 3` -> `"수박수"`
- `n = 4` -> `"수박수박"`

## 복잡도 (선택)

- 시간: O(n)
- 공간: O(n)
