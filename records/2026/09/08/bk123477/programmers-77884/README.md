## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
`left`부터 `right`까지의 모든 수 중에서 약수의 개수가 짝수인 수는 더하고, 홀수인 수는 뺀 총합을 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
어떤 수가 완전제곱수(`num**0.5 % 1 == 0`)이면 약수의 개수가 홀수라는 수학적 성질을 이용하여, 조건에 따라 해당 수를 빼거나 더한다.

## 확인한 예제 / 경계 조건

- `left = 13, right = 17` -> 16만 완전제곱수로 홀수 개 -> `13 + 14 + 15 - 16 + 17 = 43`
- `left = 24, right = 27` -> 25만 완전제곱수 -> `52`

## 복잡도 (선택)

- 시간: O(right - left + 1)
- 공간: O(1)
