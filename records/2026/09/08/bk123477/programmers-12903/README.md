## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
단어 `s`의 가운데 글자를 반환한다. 단어의 길이가 짝수라면 가운데 두 글자를 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
문자열의 길이가 짝수인지 홀수인지 판별한 뒤, 짝수이면 가운데 두 글자를 슬라이싱(`s[len(s)//2-1:len(s)//2+1]`)하고 홀수이면 가운데 한 글자(`s[len(s)//2]`)를 반환한다.

## 확인한 예제 / 경계 조건

- `s = "abcde"` -> `"c"` (길이 5, 홀수)
- `s = "qwer"` -> `"we"` (길이 4, 짝수)

## 복잡도 (선택)

- 시간: O(1)
- 공간: O(1)
