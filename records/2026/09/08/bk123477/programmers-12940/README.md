## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
두 수 `n`과 `m`의 최대공약수와 최소공배수를 구해 `[최대공약수, 최소공배수]` 형태로 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`2`부터 `min(n, m)`까지 순회하며 공약수 중 최댓값을 찾아 최대공약수를 구하고, 소인수들을 차례대로 나누어가며 누적 곱하여 최소공배수를 구한다.

## 확인한 예제 / 경계 조건

- `n = 3, m = 12` -> `[3, 12]`
- `n = 2, m = 5` -> `[1, 10]`

## 복잡도 (선택)

- 시간: O(max(n, m))
- 공간: O(log(max(n, m)))
