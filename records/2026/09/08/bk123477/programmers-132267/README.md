## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
빈 병 `a`개를 가져다주면 콜라 `b`병을 주는 마트에서, 빈 병 `n`개를 가져다주었을 때 최대로 받을 수 있는 콜라 병 수를 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
빈 병 수가 `a`개 이상인 동안 반복하며, 교환으로 얻은 병 수(`(n // a) * b`)를 정답에 누적하고 남은 병(`n % a`)과 새 병을 합쳐 `n`을 갱신한다.

## 확인한 예제 / 경계 조건

- `a = 2, b = 1, n = 20` -> 19
- `a = 3, b = 1, n = 20` -> 9

## 복잡도 (선택)

- 시간: O(log_a n)
- 공간: O(1)
