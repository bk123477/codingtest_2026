## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
자연수 `n`을 3진법으로 변환한 뒤 앞뒤로 뒤집고, 이를 다시 10진법으로 표현한 수를 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`n`을 3으로 나눈 나머지를 차례로 리스트에 담아 뒤집힌 3진법 자릿수를 구하고, 각 자릿수에 해당하는 3의 거듭제곱을 곱해 누적하여 10진법으로 복원한다.

## 확인한 예제 / 경계 조건

- `n = 45` -> 3진법 `1200` -> 뒤집으면 `0021` -> 10진법 `7`
- `n = 125` -> 3진법 `11122` -> 뒤집으면 `22111` -> 10진법 `229`

## 복잡도 (선택)

- 시간: O(log_3 n)
- 공간: O(log_3 n)
