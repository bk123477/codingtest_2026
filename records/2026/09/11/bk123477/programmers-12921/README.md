## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
정수 `n`이 주어질 때 1부터 `n` 사이에 있는 소수의 개수를 구한다. `n`은 2 이상 1,000,000 이하이다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
2부터 `n`까지의 각 수를 후보로 두고, 2부터 해당 수의 제곱근까지 나누어지는 수가 있는지 검사한다. 나누어지는 수가 없으면 소수로 판정해 개수를 센다.

## 확인한 예제 / 경계 조건

문제 제공 예제의 예상 결과는 `n=10`일 때 `4`, `n=5`일 때 `3`이다. 경계 조건 `n=2`에서는 소수 `2` 하나이므로 예상 결과는 `1`이다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: 최악의 경우 `O(n√n)`
- 공간: `O(1)`
