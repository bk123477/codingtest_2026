## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
배열 `nums`에서 서로 다른 3개를 골라 합한 값이 소수가 되는 조합의 개수를 구한다. 원소 수는 3 이상 50 이하이고 각 원소는 1 이상 1,000 이하이다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`combinations(nums, 3)`으로 가능한 세 수의 조합을 모두 순회한다. 각 합에 대해 2부터 제곱근까지 나누어 소수 여부를 판정하고, 소수인 조합을 센다.

## 확인한 예제 / 경계 조건

문제 제공 예제의 예상 결과는 `[1,2,3,4]`에서 `1`, `[1,2,7,6,4]`에서 `4`이다. 원소가 정확히 3개인 경우에는 유일한 조합의 합만 소수인지 판정하면 된다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: `O(C(N,3)√V)` (`N`은 원소 수, `V`는 세 수의 합)
- 공간: 조합 반복자를 제외한 추가 공간 `O(1)`
