## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열 `s`의 각 문자를 `skip`에 포함된 알파벳은 건너뛰면서 `index`칸 뒤의 알파벳으로 바꾼다. 알파벳 끝을 넘으면 처음으로 순환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
전체 알파벳에서 `skip`의 문자를 뺀 집합을 만들고 정렬해 사용할 알파벳 순서를 구성한다. 각 문자의 현재 위치에 `index`를 더한 뒤 허용 알파벳 수로 나눈 나머지를 사용해 결과를 만든다.

## 확인한 예제 / 경계 조건

문제 제공 예제 `s="aukks"`, `skip="wbqd"`, `index=5`의 예상 결과는 `"happy"`이다. `index`가 허용 알파벳 개수보다 커도 나머지 연산으로 순환하며, `skip`에 포함되지 않은 문자는 모두 변환 대상이다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: `O(|s| + |skip|)` (알파벳 크기 26은 상수)
- 공간: `O(|s| + |skip|)` (결과 문자열 포함)
