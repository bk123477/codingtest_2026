## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
스테이지에 도달했지만 아직 클리어하지 못한 사용자 수를 도달한 사용자 수로 나눈 실패율을 계산한다. 실패율이 높은 스테이지부터, 같은 경우에는 번호가 작은 순서로 정렬한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
스테이지별 현재 도전 사용자 수를 배열에 세고, 전체 도달 사용자 수를 유지하면서 1번부터 `N`번까지 실패율을 계산한다. 해당 스테이지에서 멈춘 사용자를 도달 인원에서 제외한 뒤 실패율 내림차순·번호 오름차순으로 정렬한다.

## 확인한 예제 / 경계 조건

문제 제공 예제의 예상 결과는 `N=5`, `stages=[2,1,2,6,2,4,3,3]`에서 `[3,4,2,1,5]`, `N=4`, `stages=[4,4,4,4,4]`에서 `[4,1,2,3]`이다. 도달 인원이 0명이 된 뒤의 스테이지는 실패율을 0으로 처리한다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.

## 복잡도 (선택)

- 시간: `O(M + N log N)` (`M`은 `stages`의 길이)
- 공간: `O(N)`
