## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
문자열의 첫 글자를 기준으로 같은 글자와 다른 글자의 개수를 왼쪽부터 센다. 두 개수가 같아지는 순간 문자열을 나누는 과정을 반복해, 분해된 문자열의 개수를 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
문자를 `deque`에서 하나씩 꺼내 현재 조각의 기준 글자 `x`와 두 종류의 개수를 갱신한다. 두 개수가 같아지면 조각 수를 증가시키고 카운터를 초기화하며, 끝까지 남은 조각도 하나로 센다.

## 확인한 예제 / 경계 조건

문제 제공 예제의 예상 결과는 `"banana"`에서 `3`, `"abracadabra"`에서 `6`, `"aaabbaccccabba"`에서 `3`이다. 문자열 길이가 1인 경우에는 남은 조각 하나로 처리되어 예상 결과는 `1`이다. 직접 실행 여부와 채점 결과는 별도로 기록하지 않았다.
