## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
매일 새 가수의 점수를 반영해 상위 `k`개의 점수만 명예의 전당에 유지하고, 그중 최하위 점수를 날마다 반환한다. 처음 `k`일 동안은 지금까지 나온 점수 모두가 목록에 포함된다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
최소 힙에 명예의 전당 점수만 저장해 최솟값을 바로 확인한다. `k`개가 찬 뒤에는 최솟값을 꺼내 새 점수와 비교하고, 더 큰 점수가 들어올 때만 교체해 매일 힙의 최솟값을 기록한다.

## 확인한 예제 / 경계 조건

- `k = 3, score = [10, 100, 20, 150, 1, 100, 200]` -> `[10, 10, 10, 20, 20, 100, 100]`
- `k = 4, score = [0, 300, 40, 300, 20, 70, 150, 50, 500, 1000]` -> `[0, 0, 0, 0, 20, 40, 70, 70, 150, 300]`
- 점수가 현재 최하위 점수보다 작거나 같으면 기존 명예의 전당을 유지한다.

## 복잡도 (선택)

- 시간: O(S log K) (`S`는 `score` 길이, `K`는 `k`)
- 공간: O(K)
