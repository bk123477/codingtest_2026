## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
두 정수 배열을 각각 길이 `n`의 이진 지도 행으로 해석한다. 같은 위치에서 어느 한 지도라도 벽이면 `#`, 두 지도 모두 공백이면 공백인 최종 지도를 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
각 정수를 나머지 연산과 정수 나눗셈으로 `n`자리 이진 배열로 변환해 `map1`, `map2`에 저장한다. 같은 위치의 두 값 중 하나라도 `1`이면 `#`, 둘 다 `0`이면 공백을 이어 붙여 결과 행을 만든다.

## 확인한 예제 / 경계 조건

- `n = 5`, `arr1 = [9, 20, 28, 18, 11]`, `arr2 = [30, 1, 21, 17, 28]` -> `["#####", "# # #", "### #", "#  ##", "#####"]`
- `n = 6`, `arr1 = [46, 33, 33, 22, 31, 50]`, `arr2 = [27, 56, 19, 14, 14, 10]` -> `["######", "###  #", "##  ##", " #### ", " #####", "### # "]`
- 이진 표현이 `n`자리보다 짧은 수는 앞쪽을 `0`으로 채워 지도 폭을 맞춘다.

## 복잡도 (선택)

- 시간: O(N²) (`N`은 지도의 한 변 길이)
- 공간: O(N²)
