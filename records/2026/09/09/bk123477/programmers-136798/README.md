## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
1번부터 `number`번 기사까지 각 번호의 약수 개수를 공격력으로 정한다. 공격력이 `limit`을 초과하면 `power`로 바꾸고, 모든 기사가 사용할 무기의 총 공격력(필요한 철의 무게)을 구한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
각 수를 `1`부터 제곱근까지 나누어 약수 쌍을 세고, 제곱수의 제곱근은 한 번만 반영한다. 약수 개수가 `limit`보다 크면 `power`를 더하고, 그렇지 않으면 약수 개수를 더해 총합을 계산한다.

## 확인한 예제 / 경계 조건

- `number = 5, limit = 3, power = 2` -> `10`
- `number = 10, limit = 3, power = 2` -> `21`
- 제곱수는 가운데 약수를 중복으로 세지 않아 약수 개수가 정확히 계산된다.

## 복잡도 (선택)

- 시간: O(N√N) (`N`은 `number`)
- 공간: O(1)
