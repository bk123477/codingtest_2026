## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
사람 이름별 그리움 점수가 주어질 때, 각 사진에 등장한 사람들의 점수를 합산해 사진별 추억 점수를 반환한다. 점수가 등록되지 않은 이름은 합산하지 않는다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
`name`과 `yearning`을 `defaultdict`에 이름과 점수의 쌍으로 저장한다. 각 사진의 이름을 순회하며 딕셔너리에서 점수를 조회해 합산하고, 없는 이름은 기본값 `0`으로 처리한다.

## 확인한 예제 / 경계 조건

- `name = ["may", "kein", "kain", "radi"]`, `yearning = [5, 10, 1, 3]`, `photo = [["may", "kein", "kain", "radi"], ["may", "kein", "brin", "deny"], ["kon", "kain", "may", "coni"]]` -> `[19, 15, 6]`
- `name = ["kali", "mari", "don"]`, `yearning = [11, 1, 55]`, `photo = [["kali", "mari", "don"], ["pony", "tom", "teddy"], ["con", "mona", "don"]]` -> `[67, 0, 55]`
- 사진에 등록되지 않은 이름만 있으면 점수는 `0`이다.

## 복잡도 (선택)

- 시간: O(M + P) (`M`은 `name` 길이, `P`는 모든 사진에 등장한 이름 수의 합)
- 공간: O(M)
