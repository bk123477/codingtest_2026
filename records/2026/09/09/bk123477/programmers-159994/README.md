## 문제

<!-- 원문 전체를 옮길 필요 없이, 요구사항과 핵심 제약을 짧게 요약하세요. -->
순서를 바꿀 수 없는 두 카드 뭉치에서 각 뭉치의 맨 앞 카드만 차례로 사용해 `goal` 단어 배열을 만들 수 있는지 판별한다. 모든 단어를 순서대로 사용할 수 있으면 `"Yes"`, 아니면 `"No"`를 반환한다.

## 풀이

<!-- 접근 방법과 그 이유를 1~3줄로 작성하세요. -->
두 카드 뭉치를 가리키는 인덱스 `i`, `j`를 두고 `goal`을 앞에서부터 순회한다. 현재 목표 단어가 어느 카드 뭉치의 현재 위치와 일치하면 해당 인덱스만 증가시키고, 둘 다 일치하지 않으면 즉시 `"No"`를 반환한다.

## 확인한 예제 / 경계 조건

- `cards1 = ["i", "drink", "water"]`, `cards2 = ["want", "to"]`, `goal = ["i", "want", "to", "drink", "water"]` -> `"Yes"`
- `cards1 = ["i", "water", "drink"]`, `cards2 = ["want", "to"]`, `goal = ["i", "want", "to", "drink", "water"]` -> `"No"`
- 한 카드 뭉치를 모두 사용한 뒤에도 남은 카드 뭉치의 현재 단어와 목표가 맞아야 한다.

## 복잡도 (선택)

- 시간: O(G) (`G`는 `goal` 길이)
- 공간: O(1)
