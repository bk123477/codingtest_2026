## 학습 주제 / 목표

스터디에서 개인 브랜치를 만들고 PR을 보내기 전에,
브랜치가 무엇을 가리키는지와 merge가 변경사항을 어떻게 합치는지 이해한다.

## 정리 내용

### 브랜치

브랜치는 커밋을 가리키는 이름이다. 같은 저장소에서 다른 작업을 진행할 때
각 작업의 커밋을 별도의 브랜치에 쌓을 수 있다.

### merge

현재 브랜치에 다른 브랜치의 변경을 합치는 작업이다.
두 브랜치에서 같은 부분을 다르게 수정한 경우에는 충돌이 발생할 수 있으며,
파일을 열어 최종 내용을 결정한 뒤 해결한 파일을 커밋한다.

### 스터디에 적용

오늘 기록은 `study/내아이디/오늘날짜` 브랜치에서 작성한다.
내일은 최신 main에서 다시 분기해 전날 리뷰 중인 변경이 섞이지 않도록 한다.

## 배운 점 / 확인한 내용

브랜치가 서로 다르면 각자의 작업을 따로 커밋할 수 있다는 점을 정리했다.
다음 실습에서는 임시 저장소에서 두 브랜치로 같은 줄을 수정해 충돌 해결을 연습할 예정이다.
