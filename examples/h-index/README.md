## 문제

논문별 인용 횟수가 주어질 때, h회 이상 인용된 논문이 h편 이상이 되는 가장 큰 h를 구한다.
논문 수는 1~1,000개이고 인용 횟수는 0~10,000이다.
전체 문제 설명과 제약은 원문 링크에서 확인한다.

## 풀이

인용 횟수를 내림차순 정렬한다. i번째 논문의 인용 횟수가 i보다 작아지는 첫 지점에서는
i편 조건을 만족할 수 없으므로 i-1을 반환한다. 끝까지 조건을 만족하면 논문 수를 반환한다.

## 확인한 예제 / 경계 조건

| 입력 | 예상 결과 | 확인 목적 |
| --- | --- | --- |
| `[3, 0, 6, 1, 5]` | `3` | 일반적인 경우 |
| `[0, 0]` | `0` | 인용된 논문이 없음 |
| `[10, 10, 10]` | `3` | 논문 수가 답의 상한 |
| `[1]` | `1` | 논문이 한 편 |

## 복잡도 (선택)

- 시간: 정렬 O(n log n), 순회 O(n)이므로 전체 O(n log n).
- 공간: Python 정렬의 작업 공간을 포함하면 O(n).

## 회고 / 리뷰 요청 (선택)

입력 리스트를 직접 정렬해 순서가 바뀐다. 원본 보존이 필요한 인터페이스라면
`sorted(citations, reverse=True)`를 쓰는 편이 나을지 검토하고 싶다.
